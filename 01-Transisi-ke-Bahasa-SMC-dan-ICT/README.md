# 01 — Transisi ke Bahasa SMC dan ICT

Folder ini adalah **jembatan** antara bahasa chart dasar dan bahasa teknis SMC/ICT.

Kalau folder `00` mengajarkan:

- high
- low
- trend
- range
- support
- resistance

maka folder ini mulai mengubahnya menjadi bahasa seperti:

- liquidity
- draw on liquidity
- premium/discount
- IPDA
- AMD

---

## Prasyarat

Sebelum masuk ke sini, pastikan Anda sudah menyelesaikan folder `00`.

Kalau Anda masih bingung membaca candle, trend, range, atau level harga penting, kembali dulu ke folder `00`.

---

## Fokus Folder Ini

- mengubah cara pandang dari level biasa ke level berbasis tujuan harga
- mengenalkan kenapa high dan low bisa menjadi target
- mulai memahami logika narasi market
- mengenalkan istilah dasar SMC/ICT tanpa langsung lompat ke model entry

---

## Cara Belajar Folder Ini

1. baca pelan
2. jangan hafal semua istilah sekaligus
3. cocokkan setiap istilah dengan chart
4. kalau bingung, buka lagi `Bab 07` di folder `00`

Folder ini bukan tempat untuk langsung mencari setup. Ini tempat untuk **menerjemahkan bahasa awam ke bahasa teknis**.

---

## Hasil Belajar yang Diharapkan

Setelah folder ini selesai, Anda diharapkan:

- tidak kaget lagi dengan istilah `liquidity`
- memahami bahwa harga sering bergerak menuju target tertentu
- siap masuk ke struktur dan likuiditas formal di folder `02`
