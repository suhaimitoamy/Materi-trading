# 07 — Sistem Indikator dan Translasi Logika

Folder ini **bukan prioritas pertama** untuk pemula nol.

Folder ini dibuat untuk pembaca yang sudah cukup matang dalam:

- membaca chart manual
- membedakan setup valid dan tidak valid
- menyusun aturan entry

---

## Kapan Masuk ke Folder Ini

Masuk ke folder ini setelah Anda:

- menyelesaikan `06`
- mulai disiplin dengan `08`
- sudah mencoba `10`

Kalau masuk terlalu cepat, Anda akan tergoda mencari indikator yang menggantikan pemahaman.

---

## Fokus Folder Ini

- mengubah konsep menjadi rule
- state engine
- scoring
- dashboard
- alert logic
- batas indikator

---

## Cara Belajar Folder Ini

- lihat folder ini sebagai latihan membuat logika lebih objektif
- jangan memperlakukan indikator sebagai jalan pintas
- pahami bahwa mesin hanya sebaik aturan yang Anda bangun

---

## Hasil Belajar yang Diharapkan

Setelah folder ini selesai, Anda diharapkan:

- mampu menerjemahkan konsep discretionary menjadi aturan yang bisa diuji
- lebih sadar batas indikator
- siap membangun sistem bantu yang tidak merusak pembacaan chart

---

## Lanjut Setelah Ini

Folder ini bisa dipakai berulang sambil menjalani:

- `08 — Jurnal dan Psikologi Pemula`
- `10 — Case Studies dan Backtesting`
- `09 — Advanced Concepts dan Model Market`
